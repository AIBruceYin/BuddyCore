# 声线素材（园丁，本地说明）

> 本文件位于未跟踪目录中，属于本机说明，不是仓库内容；仓库内的登记信息在 [../voice-of-lisa.beck.md](../voice-of-lisa.beck.md)。

本目录保存从游戏内语音抓取并做过人声/伴奏分离的音频，仅用于内部比对试听。文件体积大（约 29.5 MB）且来源为游戏素材，版权与授权状态均未确定，因此当前**保持未跟踪、不提交**；是否版本化需要先确认授权与仓库体积（见文末"待确认"）。

## 内容

| 子目录 | 内容 | 说明 |
| --- | --- | --- |
| `v1/` | 旧配音版本（园丁-全旧、扭转星辰-旧、收藏-旧1、斯凯克劳-火旧1、斯凯克劳-第一次对话旧1） | 每个条目含原始 `.m4a`、分离后的 `-vocals.mp3` 与 `-music.mp3`；部分条目只有 `.m4a` 与人声轨 |
| `v2/` | 新配音版本（新配音1、新配音2） | 同上 |

合计 18 个文件、约 29.5 MB（`v1` + `v2`）。

## 来源与制作

- 原始音频来自 B 站、小红书等公开试听内容，按 [docs/how-to-prepare-audio.md](../../../docs/how-to-prepare-audio.md) 记录的方式用系统混音录制。
- 人声/伴奏分离使用 `vocalremover.org`（网页手工处理）或移动端 AudioWeaver，产物即 `-vocals.mp3` 与 `-music.mp3`。
- 文件名中的"旧/新"指配音版本，"全旧"指整段旧版配音合集。

## 授权状态

**未授权（待核实）。** 这些音频是他人表演与录音的衍生物，版权不属于本项目。在拿到明确许可之前：

- 不得用于声音复刻（含火山引擎声音复刻）、模型训练或任何形式的再发布；
- 不得作为发布素材或固件资源打包；
- 仅限本机内部试听与音色比对。

对应的计划条目是 [实施计划](../../../docs/plan.md) 阶段 6「特定声线」，当前状态为"受阻：待授权"。
