# Datasets

每个角色或任务对象使用一个独立子目录，资料不得混放：

```text
datasets/
|-- README.md
`-- Lisa.Beck/
    |-- README.md
    |-- Lisa.Beck.md
    |-- action-of-lisa.beck.md
    |-- skin-of-lisa.beck.md
    `-- voice-of-lisa.beck.md
```

新增对象时，建立稳定的对象目录名，并在此登记用途、资料来源和授权状态。未核实的设定需标注待核实。语音试听链接仅作参考，不代表声音克隆、训练或分发授权。
