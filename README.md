# 目标
Lisa Beck 从虚拟走进现实，随时在我身边。

# 名字
Lisa Beck 是出生时的本名
Emma Woods 是逃出疯人院后，自己给自己改的新名字（游戏里角色的名字）

# 故事简单梳理

小时候：她叫Lisa Beck, 爸爸是厂长里奥.贝克，本来家庭幸福。

变故：律师骗走家产，妈妈离开，厂长破产，把Lisa送进了白沙街孤儿院。后来孤儿院改成疯人院，Lisa在里面长期遭受电击治疗，受尽折磨。

改名： 长达后她成功逃出，不想再带着过去的痛苦身份，给自己取了一个新名字，Emma Woods， 以园丁的身份生活，还开了花店。

庄园：她收到庄园的邀请函，用的名字就是Emma Woods, 所以游戏里角色板上写的就是Emma Woods.
