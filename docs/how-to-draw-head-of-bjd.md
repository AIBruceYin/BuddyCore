# 工具

1. 核心原料：丙烯 (Acrylic)
作用：作为底层附着力提供者和线条/细节刻画。

搭配原理：纯丙烯干得快、防水，但直接画在树脂上容易结块、有笔触，且难以晕染。在这套搭配中，丙烯通常不单独使用，而是与后面的酒精、定妆喷雾混合，或者用来画极细的线条（如睫毛、唇纹）。

2. 核心溶剂：酒精 2:3:5 (Alcohol)
作用：稀释剂与融合剂。这是这套搭配最精髓的地方。

2:3:5 的比例：虽然图片没说明这比例具体对应什么（通常是丙烯 : 水 : 酒精，或者丙烯 : 定妆喷雾 : 酒精），但2:3:5通常是为了调配出一种“半流质、快干、好晕染”的底妆液。

搭配原理：酒精挥发极快，能迅速带走水分，让丙烯在树脂表面快速定型。用这个比例调和出来的液体，可以像水彩一样在BJD头上薄涂、晕染（做腮红、眼影的底色），而不会留下厚重的丙烯胶感。

3. 定妆与质感：罩光定妆（丽维特、高登）
品牌解析：

丽维特 (Livot)：可能是国内常用的BJD专用消光/罩光品牌，或者是一种高性价比的哑光清漆。

高登 (Golden)：这是国际顶级的丙烯颜料/媒介品牌。高登的罩光剂（如哑光罩光漆）附着力极强，耐刮擦，是BJD圈非常推崇的定妆材料。

搭配原理：

丽维特通常用于层间定妆（每画完一层色粉或丙烯，喷一层固定，防止蹭掉）。

高登通常用于最终封层（最后喷一层，保护整个妆容，提供磨砂/哑光质感）。两者结合，兼顾了成本和最终效果。

4. 晕染与色彩：Pan粉和史明克色粉 (Pan Pastel & Schmincke)
Pan粉 (PanPastel)：一种极其细腻的软色粉，附着力好，颜色饱和度高，非常适合做大面积的底色铺陈（如全脸肤色调整、大面积眼影）。

史明克 (Schmincke)：德国顶级色粉品牌，粉质极细，色彩过渡自然。

搭配原理：色粉是BJD妆容的灵魂。它们不溶于水/酒精，必须用刷子干扫在已经“定妆”好的表面上。定妆喷雾（罩光）的作用就是给色粉提供“抓地力”——如果表面太滑，色粉挂不住；如果表面刚好微粘（喷完定妆未全干时），色粉就能完美附着。

# 实际使用流程建议：

打底：清洁BJD头。使用丙烯 + 酒精(2:3:5) 调和液，薄涂一层肤色底色，或者用Pan粉直接铺大面积腮红。然后喷一层丽维特定妆。

细节晕染：使用史明克色粉刻画眼窝、鼻影、唇部阴影。每画完一个部位，必须喷一层丽维特定妆（防止蹭花）。

线条：用纯丙烯（可加微量酒精调稀）画出睫毛、眉毛、唇线。干后喷丽维特。

最终封层：全妆完成后，最后喷上一层高登罩光定妆。高登的漆膜更硬，能提供完美的哑光质感并保护妆容不被轻易刮花。

# 注意事项：

使用酒精和定妆喷雾时，必须在通风良好的地方佩戴防毒面具/口罩，BJD妆的溶剂气味对呼吸道有刺激。

比例 2:3:5 是个人习惯配方，实际需要根据你使用的丙烯品牌和环境湿度微调（太稠加酒精，太稀加丙烯）。
